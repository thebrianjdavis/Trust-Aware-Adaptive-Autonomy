# Test Results and Coverage

The reports below are generated by the same workflow that publishes this
documentation site. On each push to `main`, the workflow checks out that commit,
runs the complete test suite, generates both reports, and deploys them with the
rest of the site. A failed test or coverage gate prevents deployment.

!!! info "Report scope"

    The published reports describe the latest successful `main` deployment.
    Pull requests run the same tests and strict documentation build, but only a
    push to `main` publishes a new site artifact.

## Generate the reports locally

After installing `requirements-dev.txt`, build the site and write the reports
into the generated site directory:

```bash
mkdocs build --strict
python -m pytest \
  --html=site/development/reports/test-results.html \
  --self-contained-html \
  --cov-report=html:site/development/reports/coverage
```

Open `site/development/test-reports/index.html` to navigate to both reports.
